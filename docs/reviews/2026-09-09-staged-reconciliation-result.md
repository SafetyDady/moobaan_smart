# ผลทยอยกระทบยอดบ้านที่เหลือ — production

เจ้าของสั่ง “ทยอย ดำเนินการให้เรียบร้อย” หลังรับรองผลบ้าน 28/95 และการเรียงบิล จึงตรวจข้อมูลใหม่และดำเนินการเป็น **14 ชุด ชุดละไม่เกิน 5 บ้าน รวม 63 บ้าน** วันที่ 9 กันยายน 2569 เวลา **15:41–15:51 น.** ไม่มีการ deploy หรือแก้ application code ในรอบนี้

## ผลรวมที่ตรวจจาก production หลังทำ

- **61 บ้าน** ที่มีเงินรับยืนยันเหลือพร้อมกับบิลค้าง ได้ใช้เงินเหลือตามเพดานและ FIFO แล้ว
- อีก **2 บ้าน (28/24, 28/39)** แก้ลำดับเงินรับที่สลับกับบิล โดยยอดชำระรวม/ยอดค้างไม่เปลี่ยน
- เพิ่มยอดกระทบบิล **153,000.24 บาท** จากเงินรับเดิม ไม่ใช่เงินรับใหม่
- สร้าง payment ACTIVE **318 รายการ** (IDs414–731) และเก็บรายการเดิม **50 รายการ** เป็น REVERSED ไม่ลบหรือเปลี่ยนยอด/เวลา/ลิงก์เดิม
- สแกนทั้ง **157 บ้าน** หลังทำ: **0 บ้าน** มีเงินยืนยันเหลือพร้อมกับบิลค้าง; 47 บ้านมีเงินเหลือแต่ไม่มีบิลค้าง, 99 บ้านมีบิลค้างแต่ไม่มีเงินยืนยันเหลือ, 11 บ้านไม่ค้างและไม่มีเงินเหลือ
- เงินรับ POSTED **283/283 รายการ** ยังตรงกับยอดและเวลาใน Statement raw rows และ chain ที่ตรวจ; ไม่พบ over-allocation, over-settlement หรือกระทบข้ามบ้าน
- สลิป PENDING/SUBMITTED ทั้ง **16 รายการ** ยังรอตรวจ ไม่ยืนยันหรือใช้ชำระบิลในงานนี้

| ยอดรวมทั้งระบบ | ก่อนรอบนี้ | หลังรอบนี้ |
|---|---:|---:|
| ยอดกระทบบิล | 243,400.50 | 396,400.74 |
| ยอดค้างบนบิล | 518,197.10 | 365,196.86 |
| เงินรับยืนยันที่ยังไม่กระทบบิล | 320,218.60 | 167,218.36 |
| ยอดค้างหักเงินยืนยันที่เหลือ | 197,978.50 | 197,978.50 |

ยอดสุทธิรวมไม่เปลี่ยน และตรวจว่าคงเดิมแยกทุกบ้าน ไม่มีการนำเงินบ้านหนึ่งไปปิดหนี้อีกบ้านหนึ่ง เงินเหลือของบ้านที่จ่ายครบเก็บไว้สำหรับบิลถัดไป ไม่คืนเงินหรือสร้างบิลใหม่อัตโนมัติในรอบนี้

## ขอบเขตและข้อยกเว้น

กลุ่มใช้เฉพาะเงินเหลือมี42บ้าน; กลุ่มจัดลำดับประวัติย้อนหลังมี19บ้าน; กลุ่มบิลพิเศษคงการจับคู่เดิมมี2บ้าน

ตรวจหมายเหตุทั้งกลุ่มที่เคย flag แล้ว พบหมายเหตุย้ายระบบ/ช่วยเพิ่มสลิป/แจ้งส่วนตัว โดยไม่ระบุบิลเป้าหมาย จึงไม่ตีความเป็นการเลือกบิลของลูกบ้าน ใบลดหนี้เดิมเก็บครบและคำนวณยอดค้างหลังเครดิต รายการ ledger REVERSED ถูกตัดออก ใช้เฉพาะ POSTED ที่มีหลักฐานยืนยันครบ

**อัปเดต 11 ก.ย.:** แก้การผูกยอดย้อนหลังของทั้งสองบ้านเสร็จแล้ว โดยเงินยืนยันยังตรง Statement และยอดรวมไม่เปลี่ยน ดู [ผลบ้าน 28/30](2026-09-11-house2830-reconciliation-result.md) และ [ผลบ้าน 28/56](2026-09-11-house2856-reconciliation-result.md). ตรวจทั้ง157บ้านไม่เหลือข้อสังเกตลำดับตามเกณฑ์นี้; สลิปรอตรวจเป็นงานแยกตามรายงานล่าสุด รายละเอียดด้านล่างเป็นผล ณ 9 ก.ย.

**28/30 และ 28/56 มีบิลพิเศษ:** คงการจับคู่เดิมทั้งหมด รวม payment ของบิลพิเศษ เพิ่มเฉพาะเงินที่ยังไม่เคยใช้ไปชำระบิลค้างตาม FIFO:

| บ้าน | ยอดค้างก่อน → หลัง | เงินเหลือหลัง |
|---|---:|---:|
| 28/30 | 600 → 0 | 602.70 |
| 28/56 | 3,000 → 2,400 | 0 |

จึงยังมี **ข้อสังเกตด้านลำดับวันที่ของประวัติ 2 บ้านนี้** โดยตั้งใจคงการจับคู่เดิมให้ที่ปรึกษาตรวจ ไม่ได้อ้างว่าได้จัดลำดับย้อนหลังใหม่ครบทุกบิลพิเศษแล้ว สถานะปัจจุบันไม่มีเงินยืนยันค้างใช้พร้อมกับหนี้เหลือ แต่การย้ายประวัติเดิมของ2บ้านนี้เป็นเรื่องแยกจากการนำเงินเหลือมาใช้

บ้าน28/95ที่แก้ไปแล้ว และอีก93บ้านนอกชุด รวม **94บ้านนอกงานรอบนี้ ไม่เปลี่ยนแถว invoice/payment**; source tables, สมาชิก, เครดิตและหลักฐานเดิมคงเดิมทั้งหมด
